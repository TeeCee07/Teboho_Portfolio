# Teboho Comfort Masiteng | Portfolio

> A modern, responsive portfolio website showcasing my skills, projects, and professional background as a final-year BSc Information Technology student at North West University.

🔗 **Live Demo:** [View Portfolio]((https://teecee07.github.io/Teboho_Portfolio/))

---

## 📖 Overview

This portfolio serves as my **virtual CV** – a comprehensive, interactive representation of my professional identity. It combines my academic background, technical skills, projects, and work experience into a visually engaging single-page application.

---

## ✨ Features

- 🌙 Dark/Light Mode toggle
- 🎯 Typing animation in hero section
- 📊 Scroll progress bar
- 🧊 Glass-morphism UI design
- ✨ Smooth scroll animations
- 📈 Animated skill bars
- 🔢 Counter animations
- 🎨 Animated particle background
- 📱 Fully responsive (desktop, tablet, mobile)
- 📄 One-click CV download (PDF)
- 🔗 Social links (GitHub, LinkedIn, Email)
- 🎯 Active navigation highlighting
- 🖱️ 3D tilt effect on project cards
- 📧 Working contact form with Formspree

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (Vanilla)
- Canvas API
- Font Awesome
- Formspree (contact form)
- GitHub Pages (hosting)

---

## 📄 Sections

- **Home/Hero** – Name, title, bio, social links, CTA buttons
- **About** – Personal summary, stats, languages
- **Resume** – Education and work experience
- **Projects** – Featured projects with tech stack and GitHub links
- **Skills** – Technical skills with animated progress bars
- **Contact** – Contact info + working contact form

## 🚀 Deployment

### Deploy to GitHub Pages

1. Push code to GitHub repository
2. Go to **Settings → Pages**
3. Select **main** branch and save
4. Site live at: `https://TeeCee07.github.io/portfolio/`
